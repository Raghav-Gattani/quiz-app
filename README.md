# 🧠 One Piece Interactive Quiz

An 8-question One Piece quiz built with HTML, CSS and JavaScript.

## Features
- Instant correct/wrong feedback, live score and progress bar
- Final rank based on score, restart button

## Run
Open `index.html` in a browser.
